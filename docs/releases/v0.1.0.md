# OpenAI 网关控制台 v0.1.0

- 发布日期：2026-08-01
- 发布类型：首次正式发布
- 版本：`0.1.0`

## 概述

`v0.1.0` 提供可本地部署的 OpenAI 兼容多渠道网关及 Vue 3 管理控制台。单个 Go 二进制同时提供网关接口和管理页面，使用 SQLite 保存配置与运行数据。

## 功能

- 兼容 `GET /v1/models`、`POST /v1/chat/completions` 与 `POST /v1/responses`，支持流式及非流式转发。
- 管理上游渠道、模型映射、访问令牌、模型授权、速率限制与并发限制。
- 提供优先级加权、成本优先和效率优先路由；支持会话亲和、响应链亲和、失败重试和分级熔断。
- 记录请求、上游尝试、路由决策、渠道切换、Token、费用和全阶段耗时；保留最近五天的明细与会话时间线。
- 支持 Codex 与 Copilot 会话识别、活动会话查询及路由诊断。Copilot 客户端必须发送 `X-Github-Copilot-Integration-Id: copilot-cli`；该内部识别头不会转发至上游。
- 提供运行总览、渠道管理、模型路由、访问令牌、调用日志、会话日志、熔断记录与系统设置。
- 管理员控制台使用安全会话 Cookie；上游密钥采用 `GATEWAY_MASTER_KEY` 加密保存，客户端令牌仅保存摘要。

## 运行要求

- Go `1.25.4`
- Node.js `^20.19.0 || >=22.12.0`
- pnpm `10.23.0`

首次运行需配置 `GATEWAY_MASTER_KEY`。首次管理员可通过 `GATEWAY_ADMIN_USERNAME` 和 `GATEWAY_ADMIN_PASSWORD` 设置；未提供时应用会生成所需凭据。生产环境应关闭自动打开浏览器、通过 HTTPS 访问控制台，并限制管理端访问范围。

## 构建与验证

```bash
go run ./tools/projectctl check
go test ./...
go vet ./...
go build -buildvcs=false ./...
pnpm --dir frontend build
```

前端资源会嵌入 Go 二进制。跨平台产物使用 `./build.sh` 构建；可通过 `PACKAGE_NAME=<name>` 指定本次产物名称。

## 限制

- 当前面向单实例 SQLite 部署，不提供跨实例共享的路由、限流或会话状态。
- 流式响应仅在首个有效输出前允许切换渠道；输出开始后发生中断不会续传到其他渠道。
- 请求与会话明细默认保留五天，日志正文可能包含敏感数据，应按最小必要原则配置和访问。
